# 🔥 Flannery Messenger

Умный мессенджер с AI-сортировкой чатов

## Возможности
- 🤖 AI-сортировка чатов по категориям
- 💣 Самоуничтожающиеся сообщения
- 👥 Группы и каналы
- 🛟 Система тикетов поддержки
- 👑 Админ-панель
- 📱 Полная адаптивность

## Установка
```bash
npm install
npm run db:init
npm start
